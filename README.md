# 小伴 · 银发 AI 私教

面向中老年用户的兴趣学习陪伴型 Web App 原型。用户可以从书法、摄影、乐器和家庭园艺中选择兴趣，观看短教程与社区分享，并进入语音或视频陪练。产品重点验证了「低门槛发现兴趣 → 持续学习 → 分享进步」的核心闭环。

## 产品亮点

- **兴趣学习首页**：今日推荐、正在学习的技能卡片和学习天数。
- **技能广场**：按全部、正在学习、未加入筛选技能，先浏览内容再决定是否加入。
- **技能课堂**：教程列表、断点续学、课程播放弹窗和「看完去陪练」入口。
- **社区分享**：查看示例视频，支持点赞、收藏、交流入口和本地上传视频预览。
- **AI 陪练交互**：语音陪练和视频陪练两种模式，提供步骤提示和练习状态反馈。
- **小伴 Mascot**：可拖动的悬浮助手，点击后打开快捷操作面板。
- **本地状态保存**：技能库和助手位置保存到浏览器 `localStorage`，刷新后可继续体验。
- **便携单文件版本**：构建脚本会将远程图片和示例视频资源内嵌到一个 HTML 文件中，便于面试演示。

## 快速开始

环境要求：Node.js 18+。

```bash
npm install
npm run dev
```

启动后打开终端提示的本地地址。生产构建：

```bash
npm run build
```

生成可离线演示的单文件 HTML：

```bash
npm run build:portable
```

输出文件为 `银发AI私教APP.html`，可直接在浏览器打开。

## 目录结构

```text

├── index.html                 # Vite 入口
├── src/
│   ├── main.jsx               # 当前默认运行的银发 AI 私教主应用
│   ├── styles.css             # 主应用样式
│   ├── conversation.jsx       # 家庭保障对话式原型（备用探索）
│   ├── conversation.css
│   ├── insurance.jsx          # 家庭保障表单式原型（备用探索）
│   └── insurance.css
├── scripts/build-portable.mjs # 生成单文件演示版本
├── vite.config.js
├── package.json
└── 银发AI私教APP.html          # 已生成的便携演示文件
```

`index.html` 当前只加载 `src/main.jsx`；`conversation.jsx` 和 `insurance.jsx` 是同一项目中的保险规划方向探索稿，不属于默认入口。

## 原型边界

这是用于产品和交互验证的前端原型，不是可直接上线的完整服务：

- 没有账号、服务端、数据库或真实 AI 接口。
- 语音/视频陪练是交互演示，不会真正分析语音或动作。
- 点赞、收藏、上传和课程进度只保存在当前页面或浏览器本地。
- 图片和示例视频在开发构建中使用远程演示资源；便携构建会尝试将资源内嵌。
- 保险规划相关文件是独立的备用原型，当前未接入主应用路由。

## 简历展示建议

建议重点展示：用户问题定义、核心用户流程、状态管理与本地持久化、可拖动助手、响应式交互，以及 `build:portable` 带来的可演示交付。面试时应明确说明哪些能力是前端原型，哪些仍需要后端、模型和合规方案支持。
